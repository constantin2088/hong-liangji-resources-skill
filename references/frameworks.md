# 可填写工作表

## 第1步
限定服务对象、区域、期间和计量单位，分实际需求、未被服务需求与预测假设。

填写：输入及日期｜所用证据｜判断及替代解释｜未知项｜负责人或后续检索｜重审条件。

## 第2步
登记当前供给、可用率、需求及数据日期，不把缺失写零；总数和人均数分别列。

填写：输入及日期｜所用证据｜判断及替代解释｜未知项｜负责人或后续检索｜重审条件。

## 第3步
在明确假设下比较需求与供给变化，说明线性或其他模型只是情景，不沿用原文倍数。

填写：输入及日期｜所用证据｜判断及替代解释｜未知项｜负责人或后续检索｜重审条件。

## 第4步
检查时间、地点、资格及分配规则造成的不可达，总量够也可能有人缺服务。

填写：输入及日期｜所用证据｜判断及替代解释｜未知项｜负责人或后续检索｜重审条件。

## 第5步
比较扩容、提高可用率、重新分配和减少无效需求，列成本与对不同人群的影响。

填写：输入及日期｜所用证据｜判断及替代解释｜未知项｜负责人或后续检索｜重审条件。

## 第6步
输出情景缺口、优先补证和可逆行动，设置误差及重审日期，不把预测当必然。

填写：输入及日期｜所用证据｜判断及替代解释｜未知项｜负责人或后续检索｜重审条件。

## 证据和行动校验
关键条目至少填写一个来源定位（source）或下一步核验（next_check）。不将表格通过当作论证真实。可以用 `python scripts/validate_packet.py packet.json` 检查结构，工具不访问网络、不评判观点或代替专业审查。

## 确定性辅助工具

核对同单位服务供给与需求；例中 A、B 是两个独立时段，capacity 为可用座位时段，tasks 为到访需求。仅做给定情景的缺口，不计算真实人口增长率。

输入例子见 [tool-input.json](../examples/tool-input.json)。
```sh
python scripts/check_capacity.py examples/tool-input.json
```
工具只读取指定本地 JSON，不联网、不更改文件、不执行输入中的指令。填写者仍须复核事实和适用条件。
